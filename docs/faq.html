frequently asked questions

faq

answers to common questions about how the app works,
what it can and can't do, and how to stay safe.

is this an official discord product?

no. this is an independent, community-made desktop tool. it is not affiliated with, endorsed by, or connected to discord inc. in any way.

where are my tokens stored?

only locally on your machine, in %APPDATA%\DiscordTokenManager. nothing is sent to any server, and the downloads contain no tracking.

is using tokens safe?

automated use of discord accounts (including token-based login and bulk actions) can violate discord's terms of service. use this tool only on accounts you own, responsibly, and at your own risk.

what are the system requirements?

windows 10 or 11, 64-bit. the compact exe and setup installer need write access to a local folder and an internet connection for discord's api. no admin rights required.

how do i uninstall?

if you used the setup edition, run uninstall discord multiple vc joiner from the start menu. for compact or portable editions, just delete the file or folder.
