Why you'll like it

Resizable panels

Accounts, servers, and voice channels each live in their own draggable pane. Drag the dividers, double-click to reset, and the layout is remembered between sessions.

Bulk validation

Check every token in one pass with smart concurrency and rate-limit handling. All / Valid / Invalid filters keep the bad ones out of your way.

One-click voice join

Pick a server, pick a channel, and join selected accounts to it — with configurable delays, proxies, and microphone/speaker (self-mute & self-deaf) toggles.

Privacy first

Everything is stored locally in your user profile. The app never uploads your tokens anywhere.

Modern Windows UI

Dark theme with Windows 11 Mica/Acrylic backdrop, command palette (Ctrl+Shift+P), and dense/compact card modes.

FAQ

Is this an official Discord product?

No. This is an independent, community-made desktop tool. It is not affiliated with, endorsed by, or connected to Discord Inc. in any way.

Where are my tokens stored?

Only locally on your machine, in %APPDATA%\DiscordTokenManager. Nothing is sent to any server, and the downloadable files contain no tracking or telemetry.

Is using tokens safe?

Automated use of Discord accounts (including token-based login and bulk actions) can violate Discord's Terms of Service and may result in account restrictions. Use this tool only on accounts you own, responsibly, and at your own risk.

What are the system requirements?

Windows 10 or 11, 64-bit. The compact EXE and setup installer need write access to a local folder (%LOCALAPPDATA%) and an internet connection for Discord's API. No admin rights are required.

How do I uninstall?

If you used the Setup edition, run Uninstall Discord Token Manager from the Start Menu. For Compact or Portable editions, just delete the file or folder.

About this project

Discord Token Manager is a Windows desktop app written in Python with a CustomTkinter interface. It started as a personal utility to replace juggling a plain-text file of tokens, and grew into a full three-pane manager with validation, voice joining, proxying, and a modern look.

Track record

  • Token import from file or clipboard
  • Bulk validation with rate-limit safety
  • Server pinning & smart search
  • Voice join with delay, proxy & self-deaf/mute controls
  • Activity/reason presets
  • Automatic validation on startup

The code

  • Python 3 · CustomTkinter · PyInstaller builds
  • Clean architecture: domain core, services, controllers, ui
